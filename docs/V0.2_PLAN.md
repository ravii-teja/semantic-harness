# semantic-harness v0.2.0 — P0 Sprint (COMPLETED)

All 4 P0 gaps from `GAP_ANALYSIS.md` closed, plus bug fixes.
**Verification: 70/70 tests pass · ruff clean · mypy clean · end-to-end smoke test green.**

## Phase 1 — Bug Fixes ✅

- [x] **1.1 Failure poisoning** (`core/loop.py`) — LLM errors no longer cached as verified
      procedures; new `STEP_ERROR` event emitted, `record_failure()` called instead
- [x] **1.2 LTM persistence** (`core/agent.py`, `AgentConfig.ltm_db_path`) — agents now
      persist to SQLite file by default (`./semantic_agent.db`)
- [x] **1.3 Dead code** (`memory/short_term.py`) — removed unused `_token_count`

## Phase 2 — Structured Output + Multi-Step Loop ✅

- [x] `run()`/`arun()` accept `output_schema=<PydanticModel>`
- [x] `extract_json()` in `semantics/c2c.py` — code-fence and prose tolerant JSON extraction
- [x] Invalid output → `retry_prompt` fed back for LLM self-correction;
      `SEMANTIC_VALIDATE_OUTPUT` events emitted
- [x] Hard single-step `break` removed — loop iterates until completion/budget/error
- [x] Task seeded once into conversation so retries stack correctly

## Phase 3 — Native Tool Calling ✅

- [x] New `tools.py`: `@tool` decorator, `function_to_schema()` (type hints → JSON Schema),
      `ToolRegistry` with safe `execute()` (errors returned as strings the LLM can read)
- [x] AgentLoop dispatches `message.tool_calls`: emit `TOOL_CALL`/`TOOL_RESULT`,
      persist exchange via `ShortTermMemory.add_message()`
- [x] Public documented agent methods auto-register as tools (`register_object`);
      `run`/`arun` never exposed; `AgentConfig.enable_tools` flag

## Phase 4 — CodeAct Execution Strategy ✅

- [x] `execution/repl.py`: `PythonREPL` — restricted builtins sandbox, persistent namespace,
      trailing-expression capture, per-run `print` capture (thread-safe, no global stdout
      mutation), timeout with thread abandonment
- [x] `execution/codeact.py`: `CodeActStrategy` + `extract_code()` — code fences executed,
      observations fed back, `FINAL:` marker protocol, schema validation on final answers
- [x] `AgentConfig.execution_strategy: "tools" | "codeact"` (+ `repl_timeout`)

## Phase 5 — Event Persistence ✅

- [x] `core/persistence.py`: `JSONLSessionLog` — thread-safe append-only log,
      non-serializable payloads stringified, corrupt lines skipped on replay
- [x] `EventBus.on_any()` wildcard listeners; `EventBus.load_history(path)` replay
- [x] `EventType` exported from package root

## Phase 6 — Tests & Verification ✅

- [x] `tests/test_v02.py`: 39 new tests (70 total) covering all phases incl. regressions:
      failure-poisoning, retry exhaustion, task-seeded-once, tool dispatch, sandbox escape

- [x] `[tool.ruff]` + `[tool.mypy]` configured in `pyproject.toml`; both pass clean
- [x] End-to-end mock-LLM integration verified: tool round → invalid JSON retry →
      schema-valid result → 18-event timeline persisted & replayed
